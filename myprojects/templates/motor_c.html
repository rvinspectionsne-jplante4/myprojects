Class C Motor Homes

🔵 Class C motor homes typically have the same amenities as the larger Class As, but are easier to maneuver and at a lower cost.

🔵 Class C motor homes are easily distinguished from Class B+ by having a bunk over the cab.

🔵 Class C coaches often have the same appliances and towing capacities as larger coaches and are typically powered by gasoline engines rather than diesels.
